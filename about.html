About Our Project

About SmartCampus

Building a better campus through student feedback and continuous improvement.

Our Mission

SmartCampus is a Student Feedback Management System that allows students to share their opinions about teaching, infrastructure, library services, laboratories, and other campus facilities.

The goal is to understand student experiences, identify areas for improvement, and support a better learning environment.

How It Works

1. Submit Feedback

Students provide their details, select a category, give a rating, and share their suggestions.

2. Explore Feedback

Submitted feedback can be viewed and searched by category or rating.

3. View Analytics

The dashboard presents ratings and category-wise statistics to help identify improvement areas.

Technologies Used

HTML — creates the webpage structure.

CSS — designs the layout, colors, and appearance.

JavaScript — handles feedback submission and statistics.

Git and GitHub — manage and store the project code.

Docker and Nginx — package and serve the website.

Jenkins — supports the project build and deployment workflow.
